💥 SQL 인젝션(SQL Injection)이란?

사용자가 입력한 값을 검증 없이 SQL 문에 문자열로 그대로 이어 붙일 때, 공격자가 따옴표·주석·UNION 같은 SQL 문법을 입력에 섞어 넣어 원래 의도와 다른 쿼리를 실행시키는 공격입니다. 로그인 우회, 개인정보 탈취, 데이터 변조·삭제까지 이어질 수 있어 OWASP가 꼽는 대표적인 웹 취약점입니다.
