# 🛡️ SQLi·Guard — SQL 인젝션 공격·방어 가이드 사이트

SQL 인젝션을 **직접 뚫어보고 직접 막아보며** 원리와 방어를 배우는 교육용 웹사이트입니다.
일부러 취약하게 만든 더미 회원 포털을 공격해 보고, 같은 공격이 **화이트리스트 검증·ORM·파라미터화 쿼리·WAF**로
어떻게 막히는지 실행되는 SQL과 함께 눈으로 비교합니다.

> ⚠️ **교육용** 학습을 위해 의도적으로 취약점을 넣어 두었습니다.
> 실제로 이게 먹힐리도 없고 시도조차도 하지 마세요

## 실행 방법

```bash
npm install      # 최초 1회 (express 설치)
npm start        # http://localhost:3000
```

Node.js **22.5 이상**이 필요합니다 (내장 `node:sqlite` 모듈 사용 — 별도 네이티브 빌드 불필요).

## 구성 페이지

| 페이지 | 설명 |
|--------|------|
| **홈** (`/`) | SQL 인젝션 개요와 학습 경로 안내 |
| **더미 사이트** (`/dummy.html`) | 취약한 회원 포털. 복사용 페이로드로 로그인 우회·회원정보 유출을 직접 재현. 방어 모드/WAF 전환, 무차별 대입 경고 |
| **보안 실습실** (`/lab.html`) | 같은 페이로드를 4가지 모드로 한 번에 실행해 생성 SQL을 비교. DB 들여다보기 |
| **방어 가이드** (`/guide.html`) | 원리·공격 유형·방어 4종(다국어 코드 예시)·WAF·무차별 대입·체크리스트 |
| **암호화 가이드** (`/crypto.html`) | 해시(단방향)·대칭키·공개키(비대칭) 비교, 비밀번호 해시 저장·전자서명·HTTPS 하이브리드 (다국어 코드 예시) |

## 다루는 방어 기법

1. **파라미터화 쿼리** (가장 중요) — 값을 `?` 자리표시자에 바인딩
2. **ORM 프레임워크** — 객체로 조건을 다뤄 내부적으로 파라미터 바인딩 (`src/orm.js`)
3. **화이트리스트 입력 검증** — 허용된 문자·형식만 통과
4. **WAF (웹 방화벽)** — 공격 시그니처 선차단 (`src/waf.js`)
5. **무차별 대입 방어** — 반복 실패 탐지·경고·잠금 (`src/bruteforce.js`)

## 주요 실습 시나리오

- **로그인 인증 우회**: 아이디 칸에 `admin' --` → 비밀번호 없이 관리자 로그인
- **UNION 데이터 추출**: 검색창에 `%' UNION SELECT id, username, password, email FROM users -- ` → 전체 회원 계정 유출
- **비공개 글 노출**: 검색창에 `%' OR 1=1 -- `
- **무차별 대입**: 틀린 비밀번호로 반복 로그인 → 경고 → 계정 잠금
